隐私政策

**生效日期**：2026-10-11

**适用应用**：HarmonyPyIDE（包名 com.harmonyide.python）

一、我们收集哪些信息

1. 本应用**默认不收集任何个人信息**，也不联网上传任何数据。

2. 只有当你**主动点击「华为账号登录」**时，才会通过系统「华为账号」服务获取：

- unionID / openID（华为账号在本应用中的稳定标识，**不含手机号与真实姓名**）

- idToken / authorizationCode（身份校验用的临时凭证）

3. 上述信息**仅保存在本机应用私有目录**（account.json），**不上传任何服务器** —— 本应用没有自建服务端。

4. 应用**不读取**通讯录、位置、相册、麦克风、相机等任何系统数据。

二、我们如何使用信息

仅用于在应用内显示登录状态与区分本机用户。点击「退出登录」会立即清除本机保存的账号标识。

三、权限说明

本应用**未申请任何敏感系统权限**。项目文件存放在应用自身沙箱目录内，卸载应用即一并删除。

Python 代码全部在本机沙箱内运行，不访问网络（离线 pip 安装使用本地 wheel）。

四、第三方服务

仅使用系统内置的**华为账号服务（Account Kit）**用于登录；未集成广告、统计、崩溃上报或社交分享类 SDK。

五、你的权利

可随时在应用内「退出登录」删除本机账号标识，或直接卸载应用删除全部本地数据。

六、联系方式

邮箱：**请替换为你自己的联系邮箱**（上架前必须替换）
